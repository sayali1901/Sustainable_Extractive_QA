# Data

## SQuAD v2.0

Download the SQuAD v2.0 development set:

```bash
wget https://rajpurkar.github.io/SQuAD-explorer/dataset/dev-v2.0.json -O dev-v2.0.json
```

The dev set contains 11,873 questions (5,928 answerable + 5,945 unanswerable)
across 35 Wikipedia articles.

Source: https://rajpurkar.github.io/SQuAD-explorer/
